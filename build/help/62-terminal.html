The Terminal

The Terminal tab is a Linux-style shell in your browser. gpxil, gpxil2pxil and pxil are commands in it, and they run exactly as they do on a computer where the packages have been installed with pip, with the same options and the same output. Every tool in the Tools tab shows its command, with a button to run it here.

The gpxil programs

CommandWhat it does
gpxil encodea reference (FASTA, or a gpxil file such as those in /data/grch38) and a person’s VCF → a gpxil file (Make a gpxil file)
gpxil infowhat a gpxil file holds; --json prints all its metadata
gpxil validatechecks a file against the specification; it ends with status 1 if the file isn’t valid
gpxil statscounts what a file holds – bases called, substitutions and Ti/Tv, insertions, deletions, phasing, quality – for every contig or for regions; --json for programs
gpxil subsetcopies some contigs, and planes, into a new gpxil file: a working copy, made without decoding (--no-ref leaves out the reference plane); a region, such as chr17:7,661,779-7,687,546, is cut out as a window
gpxil comparetwo genomes base by base, the second as the truth: what is the same, written differently or different, with precision and recall; or a child with --father and --mother: Mendelian errors, new mutations, where each variant came from, crossovers. -o draws a region of it
gpxil rendera contig or a region as a picture: PNG for the screen, TIFF in RGB or CMYK for print
gpxil booka PDF to print, one dot per base
gpxil fastathe reference’s sequence, one of the person’s haplotypes (--which 1 or 2), or their genotype in IUPAC letters (--which iupac), as FASTA
gpxil vcfthe person’s genotypes as VCF, for the whole file or --regions of it
gpxil palettesthe colours of each palette, on screen and in print
gpxil2pxilpictures (pxil files) of genes, transcripts and proteins, from the reference or from each of the person’s haplotypes; --list lists a gene’s transcripts
pxilpxil files as FASTA; --info prints their metadata
viewer FILE [REGION]opens a gpxil file in the Viewer tab, at a region if you give one; --mode=haplotypes (or reference, genotype, variants) chooses the view, as for gpxil render, and --plane=gq shows a plane

man NAME shows examples, and NAME --help the options, from the program itself: gpxil render --help, for instance. Regions are written as genome browsers write them, chr17:7,661,779-7,687,546, counting from 1, with both ends included; commas are optional. Each program also runs as python -m gpxilwb NAME …, and gpxil as python -m gpxiltools.cli ….

cd ~/results
gpxil info /data/examples/HG002_chr17.gpxil.tif
gpxil fasta /data/examples/HG002_chr17.gpxil.tif --which iupac --region chr17:7,676,101-7,676,200 -o TP53_exon4.fa
cat TP53_exon4.fa
gpxil vcf /data/examples/HG002_chr17.gpxil.tif --region chr17:7,661,779-7,687,546 --no-nocall-blocks -o TP53.vcf
grep -v '^#' TP53.vcf | cut -f 1,2,4,5,10 | head
gpxil render /data/examples/HG002_chr17.gpxil.tif chr17:7,661,779-7,687,546 --mode variants --width 256 --scale 2 -o TP53.png
ls -l

The shell

  • It’s bash: pipes, redirection, variables, loops, functions, $( ), here-documents and scripts (bash script.sh). ↑ and ↓ bring back earlier commands, Tab completes names, Ctrl+L clears the screen.
  • Ctrl+C stops a command: the program that’s running finishes, and the rest of the line or script is skipped. Press it again to stop the program at once. For gpxil, gpxil2pxil, pxil and python, that restarts Python, so a notebook’s variables are forgotten too.
  • The text programs – cat, head, tail, grep, sed, cut, sort, uniq, wc, tr, paste, diff, column, less and others – were written for this terminal after the GNU ones. NAME --help says which options each has. So were the file programs: ls, cp, mv, rm, mkdir, find, du, tree and the rest, and zip, unzip and tar.
  • python runs scripts, python -c "…" and python -m json.tool FILE, in the same Python as the notebooks. pip install NAME adds a package for this visit.
  • curl and wget download through the browser, from servers that let web pages read them: the Gpxil browser, Ensembl’s REST API, raw.githubusercontent.com, EBI and Zenodo, among others. You don’t need them for GRCh38, which is in /data/grch38 already.
  • open FILE shows a file in its tab, nano FILE edits it in the Files tab, and download FILE (or a folder, as a .zip) saves it to your computer.
  • Not here: background jobs (&), sudo, apt and ssh, and programs that aren’t in help’s list, such as bcftools and samtools. gpxil does much of their work on gpxil files: gpxil vcf --region cuts out a region as VCF, and gpxil fasta --which 1 spells out a haplotype.
Save pictures with -o, not >

The shell’s redirection (> and |) is for text. Pictures, PDFs and gpxil files are written properly only by the program itself, so give their names with -o, as every example here does.

Several at once

A loop does the same to many regions or files. These commands spell out the bases around TP53’s codon 72 from the reference and from each of HG002’s haplotypes, then make pictures of TP53’s protein from the reference and from both haplotypes, with the transcripts from a GTF file:

mkdir -p ~/results/P72
for which in ref 1 2; do
  gpxil fasta /data/examples/HG002_chr17.gpxil.tif --which $which --region chr17:7,676,140-7,676,170 -o ~/results/P72/P72.$which.fa
done
cat ~/results/P72/*.fa
gpxil2pxil /data/examples/HG002_chr17.gpxil.tif TP53 -a /data/examples/TP53.gtf --kinds protein --haplotypes all -o ~/results/P72
pxil ~/results/P72/*.pxil.png -o ~/results/P72/TP53-proteins.fa
grep '>' ~/results/P72/TP53-proteins.fa

gpxil2pxil says how each haplotype’s protein differs from the reference’s (P72R), and pxil puts the three proteins into one FASTA file, each named by its Ensembl ID and, for a haplotype, the person and the haplotype, ready for an alignment program. Without -a, gpxil2pxil takes Ensembl’s genes and transcripts from the Gpxil browser’s gene files, so any gene of GRCh38 can be named: gpxil2pxil /data/grch38/chr17.gpxil.tif BRCA1 --kinds protein -o ~/results.

Keeping a session

export-session session.ipynb saves the commands of this session, with what they printed, as a notebook, one %%bash cell a command; so does the Save session button above the terminal. export-session session.sh saves them as a script, which runs in Jupyter or a terminal on any computer where the packages are installed (On your own computer).
