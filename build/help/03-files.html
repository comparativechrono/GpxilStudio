Your files

Your files live in your home folder, ~ (/home/user). The Files tab shows them, with the examples and the GRCh38 reference beside them, and opens each kind of file in a view that suits it. Every tab sees the same files.

The folders

FolderWhat goes there
~/genomesgpxil files you make with Make a gpxil file, and files you add from your computer in the Viewer
~/resultswhat the tools write: pictures, books, FASTA and VCF files, pxil pictures (in ~/results/pxil), and the runs of workflows
~/notebooksnotebooks, including gpxil-in-python.ipynb, which a new visitor is given
~/workflowsyour workflows, made the first time you save one
~/examplescopies of examples you ask for, which are yours to change
/data/examplesthe examples (read-only): HG002’s chromosome 17 (and a newer benchmark of it), his TP53 as a window, his father’s and mother’s (HG003 and HG004, without the reference plane), HG002’s variants around TP53 with the regions called with confidence, TP53’s transcripts, the specification’s worked example, and example workflows
/data/grch38the GRCh38 reference, a gpxil file for each chromosome (read-only), read from the Gpxil browser’s web site a piece at a time (The GRCh38 reference)

You can make any other folders you like. The tools save in ~/results unless you choose otherwise, and they can only save in your home folder.

Looking at a file

Click a file in the Files tab to open it. A gpxil file shows what it holds: its reference, its sample, its layout and a table of its contigs and planes, read straight from the file without starting Python, so even a whole genome opens at once. A pxil picture is shown large, pixel by pixel, with what it says about itself – its kind, IDs and length, where it comes from, and notes such as differs from the reference: P72R – and its sequence, read from the pixels in the page; point at a pixel to see which residue it is, and its number. Other pictures and PDFs show as they are, and text files (FASTA, VCF, BED, GTF, scripts) open in an editor: change them and press Save (Ctrl+S). Above each file, buttons offer what you can do next:

Kind of fileButtons
gpxilView (the Viewer), What’s in it (gpxil info), Check (gpxil validate), Genes as pictures (gpxil2pxil), More… (every tool that reads it)
pxilAs FASTA (pxil); under the picture, Copy the sequence too
VCFEncode as gpxil, with this file as the person’s variants
FASTAEncode as gpxil, with this file as the reference
workflowRun, and Edit (or Edit a copy of an example)
a workflow’s run (workflow-run.json)View the run: what each step did

Right-click a file, or use its ⋯ button, to rename, duplicate, download or delete it, or to copy its path. On an example, Copy to my files makes a copy you can change.

Adding files from your computer

Drag files onto the Files tab, or use its ↑ button, or My files → Add files from my computer… at the top. In the Viewer, Add a file… puts a gpxil file into ~/genomes and opens it. A file you add is kept in the browser as it is, and isn’t read until a tool needs it, so adding a big gpxil file is quick.

Where your files are kept

Your files are kept in this browser’s storage for this web site (IndexedDB), on this computer. They’re still there when you come back, unless you clear the browser’s data for the site. They aren’t sent anywhere, and nobody else can see them. Some things to know:

  • In a private or incognito window, the browser forgets everything when the window closes. The indicator at the top says when files aren’t being kept.
  • Browsers limit how much a site may keep, usually to a share of the free disk space. The indicator warns you when your files take up more than 2 GB. My files → Where are my files kept? shows how much is used.
  • A single file larger than 1 GB is there while the page is open but isn’t kept, so download it before you leave.
  • Your files are kept in this browser on this computer. Another browser, or another computer, has its own empty home folder.

Taking files elsewhere

  • A file’s Download button saves it to your computer.
  • My files → Download all my files (.zip) saves your whole home folder in one .zip file.
  • In the terminal, download FILE or download FOLDER does the same (a folder as a .zip).

Big files and Python

gpxil files are big: a chromosome is tens of megabytes, a whole genome nearly a gigabyte. The studio never copies a file of 8 MB or more into Python’s memory. Python reads it where the browser keeps it, or from the web, a piece at a time, as it needs it. A big file that a tool writes goes the other way: it is handed to the browser to keep, and Python’s copy is freed. Big files and memory explains how this works and how to make the most of it.

Starting afresh

My files → Start afresh deletes every file in your home folder from this browser, after asking you to confirm. Download what you want to keep first. The examples and the reference aren’t affected, and you are given the starting notebook again.
