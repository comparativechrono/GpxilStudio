Genes, transcripts and proteins as pxil pictures

gpxil2pxil spells out a gene from a gpxil file – from its reference, or from either of the person’s haplotypes – splices its transcripts and translates their proteins, and writes each as a pxil file: a PNG picture of the sequence, one pixel a residue, which holds the sequence exactly. A picture made from a haplotype says how it differs from the reference’s.

The form

The gpxil file
A gpxil file on the assembly of the genes (GRCh38 for the default genes): a person’s, or a chromosome of the reference from /data/grch38.
Genes
Symbols (TP53) or Ensembl gene IDs (ENSG00000141510), separated by spaces. With the Gpxil browser’s genes, an alias that names only one gene will do too.
Transcripts
the canonical transcript, Ensembl’s choice of one for each gene (the default); the MANE transcripts, MANE Select and MANE Plus Clinical, which Ensembl and NCBI agree on; every protein-coding transcript; or every transcript. In the terminal, you can also name transcripts: -t TP53-201,ENST00000420246.
Pictures of
The gene (its genomic sequence, introns included), the transcripts (spliced) and the proteins; or some of these.
From
both haplotypes for a file with a sample, else the reference (the default); the reference and both haplotypes; or one of them.
Genes from
By default, the Gpxil browser’s gene files: every transcript of Ensembl release 116 on GRCh38, read from the web a gene at a time. Or a GTF file (Ensembl or GENCODE), for another annotation or another assembly, or to work without the web: /data/examples/TP53.gtf has TP53’s lines.
Residues per row
By default, about square: in steps of 10 for a protein, 30 for a transcript (whole codons) and 100 for a gene.
Its reference
Only for a file written without its reference plane.
Only list each gene’s transcripts
No pictures: each transcript’s name, ID, biotype, protein and tags, with a star by the canonical one.
Save in
The folder for the pictures, ~/results/pxil/gene by default.

What it writes

For each transcript and each source, the pictures you asked for, named with their Ensembl IDs, and with the sample and haplotype when they come from one:

FileWhat it holds
TP53_ENSG00000141510.gene.pxil.pngthe gene’s genomic sequence, 5′ to 3′, introns and soft-masked repeats included
TP53-201_ENST00000269305.transcript.pxil.pngthe spliced transcript, 5′ to 3′
TP53-201_ENSP00000269305.protein.pxil.pngthe protein, from the start codon to the stop codon (*)
TP53-201_ENSP00000269305_HG002-hap1.protein.pxil.pngthe same protein, made from HG002’s first haplotype

It prints a line for each file, with what changed: 39 changes from the reference for a gene, 2 changes from the reference in its exons for a transcript, differs from the reference: P72R for a protein (or the same as the reference). The same notes are in each picture’s metadata, with its coordinates, exons, coding region, genetic code and source. The walkthrough says how the sequences are made, and pxil pictures of sequences how the pictures hold them.

In the terminal

gpxil2pxil /data/examples/HG002_chr17.gpxil.tif TP53 --annotation /data/examples/TP53.gtf --kinds protein --haplotypes all -o ~/results/pxil/TP53
gpxil2pxil /data/examples/HG002_chr17.gpxil.tif TP53 BRCA1 --kinds protein -o ~/results/pxil/TP53_BRCA1
Option
FILE GENE …the gpxil file (a path, or the address of one on the web), and genes
-t canonical|mane|coding|all|NAMESwhich transcripts
-k gene,transcript,proteinwhich pictures
--haplotypes ref,1,2,both,all,autofrom whom
-a GTF|FOLDER|URLthe genes, if not the Gpxil browser’s
-o FOLDER, --width Nwhere to write; residues per row
--reference FILE, --listthe reference for a file written without one; list the transcripts only

In Python

from gpxiltools import GpxilFile
from gpxil2pxil import GTF, Source, make, translate

gene = GTF("/data/examples/TP53.gtf").find("TP53")
for t in gene.select("mane"):
    print(t.name, t.id, t.protein, t.tags())
with GpxilFile("/data/examples/HG002_chr17.gpxil.tif") as g:
    spliced = Source(g, 2).spliced(gene.canonical())       # haplotype 2's transcript
    print(len(spliced.letters()), "bases; coding from", spliced.cds_start)
    files = make(g, gene, kinds=["transcript"], haplotypes=(None, 2), out_dir="/home/user/results/pxil/TP53-transcripts")
print([f.notes for f in files])
print(translate("ATGGAGGAGCCGCAGTCAGATCCTAGCTAA"))
