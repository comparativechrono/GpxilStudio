The packages in Python

These are the main functions of each package, for notebooks and scripts. Every command of the terminal is a function you can call, and every tool in the Tools tab shows its Python under The same in the terminal, and in Python. Add any box below to the open notebook with its button. A package’s own help, such as help(gpxiltools.render.render), tells you more.

Positions in Python count from 0, and the end of a region isn’t included, as in Python’s own slices. So TP53, chr17:7,661,779-7,687,546 as a genome browser writes it, is start=7_661_778, end=7_687_546.

Where things are

Opening a file, with or without its reference

GpxilFile reads only the metadata when it opens a file, and a plane only where you ask for it. A file written without its reference plane (--no-ref) needs the reference to give its bases: a FASTA file, or a gpxil file of the reference such as those in /data/grch38. gpxiltools checks it against the checksums in the file, so the wrong reference can’t be used by mistake.

from gpxiltools import GpxilFile
from gpxiltools.encode import encode

with GpxilFile("/data/examples/HG002_chr17.gpxil.tif") as g:
    print(g.sample_id, g.metadata["reference"]["name"], g.contigs)
    c = g["chr17"]
    print(f"{c.length:,} bases, {c.width:,} a row; planes {c.planes}")
    print(c.sequence(7_676_148, 7_676_160), c.entry["md5"])

# the specification's worked example, written without its reference plane, then read with it
encode("/data/examples/worked-example.fa", "/home/user/genomes/worked-example.noref.gpxil.tif",
       vcf="/data/examples/worked-example.vcf", include_ref=False, width=4)
with GpxilFile("/home/user/genomes/worked-example.noref.gpxil.tif", reference="/data/examples/worked-example.fa") as g:
    c = g["chrT"]
    print(c.planes, c.has("ref"), c.sequence())

A gpxil file on a web server opens just as a path does, and is read a piece at a time with range requests: on your own computer, GpxilFile("https://comparativechrono.github.io/Gpxil-browser/data/grch38/gpxil/chr17.gpxil.tif") reads chromosome 17 of GRCh38 from the Gpxil browser’s site. In the studio, use /data/grch38/chr17.gpxil.tif, which is the same file.

Arrays, and the codes

import numpy as np
from gpxiltools import GpxilFile
from gpxiltools import codes as C

c = GpxilFile("/data/examples/HG002_chr17.gpxil.tif")["chr17"]
start, end = 7_661_778, 7_687_546                       # TP53
ref, gt = c.read("ref", start, end), c.read("gt", start, end)
h1, h2 = C.hap1(gt), C.hap2(gt)
print("bases where haplotype 1 differs from the reference:", int((h1 != C.HAP_REF).sum()))
iupac = C.genotype_iupac(ref, gt)                        # both haplotypes as one IUPAC code a base
print(C.IUPAC[iupac[7_676_154 - 1 - start]], C.describe_gt_byte(int(gt[7_676_154 - 1 - start])))
d = C.dosage(ref, gt)                                    # copies of A, C, G and T: an (n, 4) array
print(d.shape, d[7_676_154 - 1 - start])

from gpxiltools import GpxilFile

with GpxilFile("/data/examples/HG002_chr17.gpxil.tif") as g:

gpxil2pxil: genes, transcripts and proteins

Genes come from a GTF file, or from the Gpxil browser’s gene files (BrowserData(), Ensembl’s genes on GRCh38), which the studio reads from the web. Source gives a sequence from the reference (Source(g)) or from one of the sample’s haplotypes (Source(g, 1)), with the person’s variants in it.

from gpxiltools import GpxilFile
from gpxil2pxil import GTF, Source, make
from gpxil2pxil.sequence import protein_differences

g = GpxilFile("/data/examples/HG002_chr17.gpxil.tif")
gene = GTF("/data/examples/TP53.gtf").find("TP53")
t = gene.canonical()                                   # the Ensembl canonical transcript, TP53-201
print(gene.id, len(gene.transcripts), "transcripts;", t.name, t.id, t.protein)
reference, hap1 = Source(g).protein(t), Source(g, 1).protein(t)
print(len(reference), "amino acids; haplotype 1:", protein_differences(reference, hap1))
for f in make(g, gene, kinds=["protein"], haplotypes=(None, 1, 2), out_dir="/home/user/results/pxil-python"):
    print(f.path, f.length, f.notes)

pxil files

A pxil file is a PNG picture of one sequence, so pxil.read needs nothing but Pillow. pxil.write makes one from any sequence: kind is gene, transcript, protein or sequence, and other keywords go into its metadata.

import pxil

# (a file that the box above wrote)
sequence, meta = pxil.read("/home/user/results/pxil-python/TP53-201_ENSP00000269305_HG002-hap1.protein.pxil.png")
print(meta["kind"], meta["length"], meta["notes"], sequence[60:80])
pxil.write("/home/user/results/TP53_start.pxil.png", sequence[:40], kind="protein", name="TP53, amino acids 1-40", source="HG002, haplotype 1")
print(pxil.read("/home/user/results/TP53_start.pxil.png"))
