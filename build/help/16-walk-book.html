Print a chromosome as a book

At one dot a base, a page of A4 printed at 300 dots per inch holds 6,314,220 bases, so HG002’s chromosome 17 fills 14 pages and the whole human genome about 500. Print it as a book lays a gpxil file out as a PDF of such pages, ready to print, with each page’s first and last position in its header.

1 · A proof first

A whole chromosome takes a while to lay out, so start with a proof of the first few pages. A book begins with a cover (with a key to the colours), a page on how to read it and a title page for each chromosome; with At most this many pages set to 5, the proof has two pages of bases.

Open the PDF in the Files tab, or download it. Zoom in on a page of bases and you will see each base as a square dot, as in the Viewer.

2 · Choose the look

Show
The same four views as a picture: the reference’s bases, the person’s genotype (the default for a file with a sample), their two haplotypes in pairs of rows, or their variants on the faded reference.
For
print gives each colour directly in ink (CMYK), in the palette’s own ink values, so that nothing is lost in a conversion from screen colours. the screen gives RGB colours, for a PDF to read on a computer.
Paper, Dots per inch, Dots per base
A4 at 300 dots per inch, one dot a base, is the default. At 600 dots per inch a page holds four times as many bases (the whole genome then fills about 160 pages, rather than 530); with 2 dots per base, each base is a 2 × 2 square, easier to see and to scan back.
Colours
One of gpxil’s palettes (The palettes). process uses the four printing inks at full strength, which print most faithfully.

3 · The whole chromosome

Clear At most this many pages and run it again. HG002’s chromosome 17 becomes a PDF of 17 pages, about 22 MB. It takes about half a minute on a desktop computer, longer in the browser, and longer still on a phone. A small chromosome is quicker: the mitochondrion’s 16,569 bases fit on one page.

A book of a whole genome, several hundred pages, is better made on your own computer, where it has more memory and time (On your own computer).

A book of a person is their genome

A book printed at one dot a base holds the genome in printed form: scanned at a high enough resolution, it can be read back. A book made from a person’s gpxil file – in the genotype, haplotypes or variants views – is as identifying as the file itself, and says things about their relatives too. Treat it with the same care. A book of the reference alone identifies no one.

4 · Printing it

Print at the PDF’s actual size (“100 %” or “actual size”, not “fit to page”), on the paper you chose, at the printer’s full resolution. The colours are given in device CMYK, so ask the print shop to proof them with their printer’s colour profile. Every base is a square dot with smoothing turned off, so the PDF stays sharp at any zoom.

The same in the terminal

gpxil book /data/examples/HG002_chr17.gpxil.tif -o ~/results/HG002_chr17_proof.pdf --contigs chr17 --max-pages 5
gpxil book /data/grch38/chrM.gpxil.tif -o ~/results/chrM_book.pdf --mode reference --palette process
gpxil book /data/grch38/chrM.gpxil.tif -o ~/results/chrM_book_rgb.pdf --mode reference --rgb --dpi 150 --scale 2 --title "Our mitochondria"

The same in Python

from gpxiltools import GpxilFile
from gpxiltools.book import BookLayout, make_book

layout = BookLayout(page="A4", dpi=300, margin_mm=15, scale=1)
print(f"{layout.bases_per_page():,} bases a page")
with GpxilFile("/data/grch38/chrM.gpxil.tif") as g:
    info = make_book(g, "/home/user/results/chrM_from_python.pdf", mode="reference", palette="gpxi", colorspace="cmyk", layout=layout)
print(info)
