A first session

Take ten minutes to see what gpxil files are and what you can do with them. You’ll look at the genome of a real person, HG002, around the gene TP53; draw it as a picture; see how this person’s TP53 protein differs from the reference’s; and make a small gpxil file of your own. Each step has a button that does it for you.

1 · Look at a genome

The Viewer tab shows a gpxil file as pixels, one for every base. This button opens HG002’s chromosome 17 at TP53, a gene that is mutated in many cancers. HG002 is a man whose genome has been sequenced in great depth by the Genome in a Bottle project, so his genotype is known very reliably.

Each square is one base, in rows that read from left to right and from top to bottom, like a page of text. In this view, Variants, the reference’s bases are faded, and the bases where HG002 differs from the reference stand out: orange where one of his two copies differs (heterozygous), red where both do (homozygous). Grey bases weren’t called with confidence. Point at a square to see what the file holds there.

One of the red squares is at chr17:7,676,154. There, the reference has G, and both of HG002’s copies have C. This is a common variant, rs1042522, which changes amino acid 72 of the TP53 protein from proline to arginine (P72R). Try the other views in Show, such as Haplotypes, which draws his two copies of the chromosome in two rows.

2 · See what is in the file

A gpxil file is an ordinary TIFF picture with many pages: one page for each chromosome and each plane. The ref plane holds the reference’s bases, gt the person’s genotype, flags extra facts such as which calls are phased, and gq, dp and ps how good each call is. What’s in a gpxil file, in the Tools tab, lists them. Press Run. The first run starts Python in your browser, which takes a few seconds; the very first time, it also downloads about 15 MB.

Under the form, The same in the terminal, and in Python shows exactly what the tool runs. You can use it to do the same job again without the form.

3 · Draw it as a picture

Draw a region as a picture writes the same kind of picture as a PNG file, which you can download or put in a document. The button fills in TP53 and the variants view.

4 · This person’s TP53 protein

Because a gpxil file holds the person’s genotype at every base, their own version of a gene can be read from it, spliced and translated into protein. Genes, transcripts and proteins as pxil pictures does this for each of HG002’s two copies of chromosome 17. Each picture has one pixel for each amino acid, and says how the protein differs from the reference’s. For HG002, both say differs from the reference: P72R.

The genes come from the Gpxil browser’s gene files (Ensembl, GRCh38), which are read from the web as they’re needed.

5 · A gpxil file of your own

Make a gpxil file (encode) turns a reference genome (FASTA) and a person’s variants (VCF) into a gpxil file. The specification’s worked example is tiny, ten bases and four variants, so you can see every pixel of the result.

It writes ~/genomes/worked-example.gpxil.tif. Press View under the result to look at it, then try Check, which checks it against the gpxil specification.

6 · The same in the terminal

Every step above is a command, so the whole session can be run again in one go. Run in the terminal types these commands into the Terminal tab and runs them.

gpxil info /data/examples/HG002_chr17.gpxil.tif
gpxil render /data/examples/HG002_chr17.gpxil.tif chr17:7661779-7687546 -o ~/results/TP53_variants.png --mode variants --width 256 --scale 2
gpxil2pxil /data/examples/HG002_chr17.gpxil.tif TP53 --kinds protein -o ~/results/pxil/TP53
gpxil encode /data/examples/worked-example.fa -v /data/examples/worked-example.vcf -o ~/genomes/worked-example.gpxil.tif
gpxil validate ~/genomes/worked-example.gpxil.tif

7 · Keep your work

Everything you make is kept in this browser, on this computer. To take it elsewhere, use a file’s Download button, or My files → Download all my files (.zip) at the top right.
