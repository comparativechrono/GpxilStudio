What’s in a gpxil file

gpxil info tells you what a gpxil file holds: what wrote it and when, the reference it was made on, the sample and where its calls came from, and for each contig its length, its planes, how many VCF records went into it and how many entries its sidecar has. It reads only the file’s first page, so it’s instant even for a whole genome on the web.

The form

The gpxil file
Any gpxil file: yours, an example, or a chromosome of GRCh38.
All of its metadata, as JSON
Instead of the summary, the whole of the file’s metadata (The gpxil format): every contig’s checksums and pages, the planes’ types, the sample, and the counts the encoder kept as it read the VCF.

What it says

/data/examples/HG002_chr17.gpxil.tif: gpxil 0.2, written by gpxiltools 0.6.0, 2026-10-28T15:02:24+00:00
reference: GRCh38 (Homo_sapiens.GRCh38.dna_sm.primary_assembly.fa.gz)
sample: HG002 from HG002_GRCh38_1_22_v4.2.1_benchmark.vcf.gz, callable regions HG002_GRCh38_1_22_v4.2.1_benchmark_noinconsistent.bed
layout: raster, width 8192; palette classic
contig                  length  planes                     records  sidecar
chr17               83,257,441  ref,gt,flags,gq,dp,ps      106,992   12,368

records is the number of VCF records encoded on the contig; sidecar the number of inserted sequences and complex variants kept beside the pixels (The codes). A contig of the reference alone has only the ref plane. It writes no files.

In the terminal

gpxil info /data/examples/HG002_chr17.gpxil.tif
gpxil info /data/grch38/chr17.gpxil.tif
gpxil info --json /data/examples/worked-example.gpxil.tif

gpxil info also takes the address of a file on a web server that answers range requests, and reads just its first page.

In Python

import json
from gpxiltools import GpxilFile

with GpxilFile("/data/examples/HG002_chr17.gpxil.tif") as g:
    print(g.metadata["reference"]["name"], g.sample_id)
    for c in g:   # each contig: its name, length and planes
        print(c.name, c.length, c.planes, c.entry.get("encoding", {}).get("records"))
    print(json.dumps(g.metadata["sample"], indent=2))
