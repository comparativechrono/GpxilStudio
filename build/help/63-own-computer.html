On your own computer

The packages that run here are ordinary Python packages, so every command and every piece of Python that the studio shows you works on your own computer too: in a pipeline, on a server, or on a whole genome at once, with as much memory as the computer has rather than what a browser tab allows.

Installing them

gpxiltools, gpxil2pxil and pxil are installed with pip. gpxiltools and gpxil2pxil need Python 3.10 or later, pxil 3.9 or later; pip installs what they need with them (NumPy, tifffile, imagecodecs, Pillow and jsonschema).

pip install gpxiltools gpxil2pxil pxil

If pip says it can’t find them, they haven’t reached PyPI yet. Install them from GitHub instead, which gives you the versions the studio runs (Versions, and how to cite):

pip install "git+https://github.com/comparativechrono/Gpxil-tools" "git+https://github.com/comparativechrono/pxil"
pip install "git+https://github.com/comparativechrono/gpxil2pxil"

Each package installs its command: gpxil, gpxil2pxil and pxil. They take the same options as in the Terminal tab, so the commands the Tools tab shows work on your computer once you change the paths to those of your own files. In Python, the imports are the ones in The packages in Python. The notebooks you download from the Notebook tab run in Jupyter as they are, apart from paths such as /data/examples: download the files they read too, from the Files tab.

The whole genome

The GRCh38 reference that the studio reads a chromosome at a time from the Gpxil browser is also one file of the whole genome, about 850 MB. Download it once, and give it to gpxil encode as the reference for a whole genome’s VCF:

curl -LO https://github.com/comparativechrono/Gpxil-browser/releases/download/grch38-ensembl116/GRCh38.gpxil.tif
gpxil encode GRCh38.gpxil.tif -v HG002.vcf.gz --callable HG002.callable.bed --sex XY --no-ref -o HG002.gpxil.tif
gpxil render HG002.gpxil.tif chr21 --mode variants -o chr21.png --reference GRCh38.gpxil.tif

Encoding holds a chromosome’s planes in memory while it works, about 6 bytes a base, so the largest, chromosome 1, needs about 1.5 GB. HG002’s whole genome took 12 minutes and at most 2 GB of memory on an ordinary computer, and made a file of 888 MB with the reference plane. The Gpxil browser’s downloads also have each chromosome on its own, and a checksum to check the download with. Files without their reference plane (--no-ref) are a hundred times smaller; give the reference with --reference to the commands that need its bases (The GRCh38 reference).

The studio’s own copies

You can also download the exact copies of the packages that the studio runs, in one archive with tifffile and the studio’s own runner, gpxilwb. This is handy on a computer that can’t reach PyPI or GitHub. It needs NumPy, Pillow and jsonschema (pip install numpy pillow jsonschema), and imagecodecs only for files compressed with Zstandard or LZW.

Download the packages (.zip, about 350 KB)
unzip gpxil-tools.zip -d gpxil-tools
export PYTHONPATH="$PWD/gpxil-tools"
python -m gpxilwb gpxil info HG002_chr17.gpxil.tif
python -m gpxilwb gpxil2pxil HG002_chr17.gpxil.tif TP53 --kinds protein -o pictures

python -m gpxilwb PROGRAM … runs any of the three programs, as the terminal here does; python -m gpxiltools.cli, python -m gpxil2pxil and python -m pxil run them too.

Running the studio itself

GpxilStudio is a web page with no server behind it, so you can run your own copy: download its repository from GitHub and start the small server that comes with it, which answers range requests as GitHub Pages does.

python3 serve.py 8000                      # then open http://localhost:8000/
python3 serve.py 8000 --reference DIR      # the GRCh38 reference from a copy on this computer

With --reference, the studio reads /data/grch38 from a copy of the Gpxil browser’s data/grch38 folder, so it needs the web only for Python itself, the first time.
