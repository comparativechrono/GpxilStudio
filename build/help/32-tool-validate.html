Check a gpxil file

gpxil validate checks a file against the gpxil specification, so that you – and anyone you send it to – can trust what it says. It reads the whole file a piece at a time, so it needs little memory even for a whole genome.

What it checks

  • The metadata, against the specification’s JSON schema: the keys a file must have, and the right kind of value in each.
  • The pages: that every contig has the pages its metadata names, in the right order, of the right size and type, with zero padding after the last base.
  • The codes: that every value of the ref, gt and flags planes is one the specification allows, that no haplotype claims as a variant the reference’s own base, and that phase sets are only on phased bases.
  • The sidecar: that it reads back, that each base flagged as followed by an insertion has exactly one inserted sequence and the other way round, and that every complex variant has its entry.
  • The checksums, if you ask: it spells out the reference plane’s bases and compares their MD5 and refget checksums with the metadata’s, which proves that the reference is the one the file names.

The form

The gpxil file
The file to check.
Recompute the sequences’ checksums
On by default. It reads every base of the reference plane: a few seconds for a chromosome kept here, and longer for one read from the web, which has to be downloaded (chromosome 1 is 67 MB). Untick it for a quick check.

What it says

Valid, with the number of contigs checked, or Not valid with a table of what is wrong. An error is something a reader can’t rely on: the file doesn’t follow the specification. A warning is worth knowing about but doesn’t make the file invalid. A file that isn’t gpxil, such as a TIFF picture, fails at once: its first page has no gpxil metadata. It writes no files.

In the terminal

gpxil validate /data/examples/worked-example.gpxil.tif
gpxil validate --no-digests /data/examples/HG002_chr17.gpxil.tif

It ends with exit status 0 for a valid file and 1 for one that isn’t, so a script can use it: gpxil validate FILE && echo fine.

In Python

from gpxiltools.validate import validate

report = validate("/data/examples/HG002_chr17.gpxil.tif", check_digests=False)
print("valid" if report.ok else "not valid", report.checked)
for e in report.errors:
    print("error:", e)
for w in report.warnings:
    print("warning:", w)
