Sequences as FASTA

gpxil fasta writes a sequence from a gpxil file as FASTA: the reference’s, either of the person’s two haplotypes, or their genotype as one sequence of IUPAC codes, for a region or for every contig.

The form

The gpxil file
Any gpxil file; one written without its reference needs Its reference too.
Sequence
the reference; haplotype 1 or haplotype 2: the reference with that haplotype’s variants applied – substitutions, deletions and insertions – so it can be longer or shorter than the region, with N where the haplotype wasn’t called; or the genotype, in IUPAC codes: as long as the reference, with each base where the haplotypes differ as the code of both (R for A or G, Y for C or T …). A file without a sample has only the reference.
Region
A contig, or CONTIG:START-END counting from 1. Empty: every contig, whole. In the browser, at most 50 million bases go into one file.
Save as
The FASTA file, named after the file, the region and the sequence, in ~/results.

What it writes

A FASTA file with a record for each contig or region, 60 bases a line. Its name says which sequence it is: >chr17:7661779-7687546_hap1, say, or just >chr17 for the whole of a contig’s reference. Lower case, for the reference’s soft-masked repeats, is kept.

In the terminal

gpxil fasta /data/examples/worked-example.gpxil.tif
gpxil fasta /data/examples/worked-example.gpxil.tif --which 1
gpxil fasta /data/examples/worked-example.gpxil.tif --which iupac
gpxil fasta /data/examples/HG002_chr17.gpxil.tif --which 2 --region chr17:7676101-7676200 -o ~/results/hap2_P72R.fa
Option
--which ref|1|2|iupacthe sequence (the reference if you don’t say)
--region REGIONone region; without it, every contig
-o FILEthe FASTA file; without it, the sequence is printed
--reference FILEthe reference, for a file written without one

In Python

from gpxiltools import GpxilFile
from gpxiltools.export import genotype_iupac_sequence, haplotype_sequence

with GpxilFile("/data/examples/HG002_chr17.gpxil.tif") as g:
    c = g["chr17"]
    print(c.sequence(7_676_100, 7_676_200))                          # the reference
    print(haplotype_sequence(c, 1, 7_676_100, 7_676_200).decode())   # haplotype 1
    print(genotype_iupac_sequence(c, 7_676_100, 7_676_200).decode())
