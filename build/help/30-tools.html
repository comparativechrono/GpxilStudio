The Tools tab

The Tools tab has a form for each job you can do with gpxil files. Each runs a command of gpxiltools, gpxil2pxil or pxil in the studio’s Python, exactly as the terminal would, and shows you that command, and the same job in Python, so you can do it again without the form.

The first page

The first page has the map of the formats and the tools between them: click an arrow to open its tool, or a box to see what you can do with that kind of file. Under the map, Common tasks lists the jobs most people come for, each with its tools in order and a walkthrough. All tools (on a narrow screen) or the list on the left has every tool, by group:

A tool’s form

  • Files are chosen from a list: your files first, newest at the top, then the examples, then the chromosomes of GRCh38. From my computer… adds one, and Look at it opens the chosen file where it belongs.
  • When you choose a gpxil file, the form reads what it holds – its contigs, its sample, whether it has its reference – and suggests settings to suit it: a region on its contigs, a view for its sample, the reference for a file written without one. Anything you’ve changed yourself is left alone.
  • Under Run, the form says what it still needs, if anything: a region, say, or one small enough for the browser.
  • More about this tool explains what it does, with a link to its page in the help.
  • The settings you used last are offered again when you come back to the tool on the same visit.

The same in the terminal, and in Python

Under every form, The same in the terminal, and in Python shows the command the form makes, and the same job as Python for a notebook, each with Copy and a button to run it there. As you change the form, they change too, so they’re a good way to learn the commands and the Python.

When it has run

The result says Done and how long it took, or what went wrong. What the program printed is shown under it: its progress in plain text, any warning or error in yellow. Then come the files it wrote, each with buttons to look at it, to view a gpxil file in the Viewer, to check it, to read a pxil picture’s sequence, or to download it. Some tools offer the next step, such as Check it after a gpxil file is made.

A tool writes into your home folder, ~/results unless you choose otherwise, and asks before it replaces a file that’s already there.

A file’s page

More… on a file – in the Files tab, or under a result – opens the file’s page in the Tools tab: what is in it, and every tool that reads it.

Python

The pill at the top right says how Python is: not started, starting (with what it is loading), or ready. Python starts the first time you run a tool on each visit, which takes a few seconds; the very first time, it also downloads about 15 MB, which your browser keeps. Click the pill to see the versions of the packages, or to restart Python, which forgets its variables but not your files.
