The Notebook

The Notebook tab runs Python notebooks in your browser, with gpxiltools, gpxil2pxil and pxil installed, and NumPy and Pillow beside them. They’re the same .ipynb files that Jupyter uses. Use a notebook for what the forms don’t do: your own questions of a genome, the same steps over many files, or a record of an analysis that anyone can run again.

The notebook to start from

~/notebooks/gpxil-in-python.ipynb goes through gpxil files in Python, on HG002’s chromosome 17: opening a file, a region of each plane as a NumPy array, the codes, each variant base as the file holds it, HG002’s P72R in TP53, his two sequences, a picture, the whole chromosome a piece at a time, the GRCh38 reference from the web, pictures of genes with gpxil2pxil and pxil, and the programs run from a cell. Run its cells from the top. If you’ve changed or deleted it, delete it (or rename it) and press Open the starting notebook for a fresh copy.

Work with a gpxil file pixel by pixel, in Python covers the same ground step by step, and The packages in Python lists the main functions of each package.

Working in a notebook

  • Run a cell with Shift+Enter, or press Run all to run every cell from the top. The first cell you run starts Python, which takes a few seconds; the very first time, it also downloads about 15 MB, which your browser then keeps.
  • Code and Text add cells; text cells are written in Markdown. A cell’s ⋯ menu moves, duplicates, clears or deletes it, or turns it from code into text and back.
  • Stop stops a cell that is taking too long. It restarts Python to do so, so the notebook’s variables are forgotten. Restart does the same at any time, and the list button shows the variables the notebook has now.
  • The notebook is saved among your files as you work, outputs and all. Download gives you a copy as a Jupyter notebook (.ipynb), a Python script, or a web page with its results. The notebook opens in Jupyter, JupyterLab, VS Code or Google Colab on a computer where the packages are installed (On your own computer).
  • As in Jupyter, a notebook starts in its own folder. It sees the same files as the other tabs: your home folder, /home/user (~), the examples in /data/examples, and the GRCh38 reference in /data/grch38.
  • To open a notebook you’ve made elsewhere, drag it onto the Notebook tab, or add it in the Files tab and click it.

What a cell shows

As in Jupyter, a cell shows what it prints, and the value of its last line: a number, a NumPy array, a dictionary. A Pillow picture as the last line is shown as a picture, with a button to save it as a PNG file, so render(…).to_rgb() made into an Image shows a region at once. matplotlib is loaded in the background once Python has started, and its plots are shown under the cell too. display(…) shows several things from one cell.

from PIL import Image
from gpxiltools import GpxilFile
from gpxiltools.render import render

with GpxilFile("/data/examples/HG002_chr17.gpxil.tif") as g:
    picture = render(g["chr17"], mode="variants", start=7_661_778, end=7_687_546, bases_per_row=256)
Image.fromarray(picture.scaled(2).to_rgb())

Commands in a cell

As in Jupyter, a line that starts with ! runs a command, and a line that starts with % is one of the notebook’s own commands. gpxil, gpxil2pxil, pxil and python run in the notebook’s own Python, at once; other commands run in the studio’s shell, as they would in the Terminal tab.

!gpxil info /data/examples/worked-example.gpxil.tif
!gpxil fasta /data/examples/worked-example.gpxil.tif --which 2 -o /home/user/results/worked-example.hap2.fa
!cat /home/user/results/worked-example.hap2.fa

Big files in a notebook

A notebook opens a gpxil file without reading it: GpxilFile reads the metadata, and read only the strips of a plane that hold the region you ask for. The studio never copies a file of 8 MB or more into Python’s memory, so a cell can open a whole genome, or a chromosome of the GRCh38 reference on the web, at once. What uses memory is what you read: one byte a base for each plane, so a whole chromosome 1 is 250 MB a plane. Read big regions in pieces, as the starting notebook does for chromosome 17, and let go of arrays you’ve finished with (A whole genome without running out of memory, Big files and memory).

One Python for every tab

The Tools tab, the Notebook tab and the Terminal tab share one Python. A tool you run waits until a notebook cell has finished, and the other way round. Files that one of them writes are there for the others at once.
