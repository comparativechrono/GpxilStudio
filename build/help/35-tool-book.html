Print it as a book (PDF)

gpxil book lays a gpxil file out as a PDF to print, one dot a base, page after page: a cover with a key to the colours, a page on how to read it, then each contig with a title page of its own and pages of bases, each headed with its first and last position.

The form

The gpxil file
Any gpxil file; one written without its reference needs Its reference too, as for a picture.
Only these contigs
Contigs separated by commas, such as chr17; by default, all of them.
Show
The four views of Draw a region as a picture: genotype by default for a file with a sample, else the reference.
Colours
A palette. process prints each base in one pure ink.
For
print: colours given in CMYK, in the palette’s ink values; the screen: RGB.
Paper
A4 (the default), A3, A5 or US letter.
Dots per inch
The printer’s resolution: 300 by default, one base a dot. A page of A4 at 300 dots per inch holds 2,126 bases a row and 2,970 rows: 6,314,220 bases.
Dots per base
Each base as a square of this many dots a side, to make them bigger.
Margin
In millimetres, 15 by default.
Title
For the cover; by default “The genome of HG002”, with the sample’s name, or “The GRCh38 genome”, with the reference’s.
At most this many pages
A proof of the first pages, counting the cover, the page on how to read the book and each contig’s title page: 5 pages give two pages of bases. Clear it for the whole book.
Save as
The PDF, in ~/results.

What it writes

A PDF, and how many pages it has. Each page of bases is one image with its colour table in CMYK (or RGB), with smoothing turned off, so each base stays a crisp square dot. HG002’s chromosome 17 makes 17 pages and about 22 MB; the 25 chromosomes of GRCh38 at 300 dots per inch, about 530 pages, a title page for each chromosome included.

A book of a person

Printed at one dot a base, a person’s genome can be scanned and read back. Treat a book of a person’s genotype or variants as you would their VCF.

In the terminal

gpxil book /data/grch38/chrM.gpxil.tif -o ~/results/chrM_book.pdf --mode reference
gpxil book /data/examples/HG002_chr17.gpxil.tif -o ~/results/HG002_chr17_proof.pdf --max-pages 5 --page A3 --dpi 600
Option
FILE -o BOOK.pdfthe file, and the PDF to write
--contigs A,B, --mode NAME, --palette NAMEwhich contigs, which view (genotype if you don’t say), which colours
--rgbRGB for the screen, instead of CMYK
--page A4|A3|A5|letter, --dpi N, --scale N, --margin MMthe paper, the resolution, dots per base, the margin
--title TEXT, --max-pages Nthe title; a proof of the first pages
--reference FILEthe reference, for a file written without one

In Python

from gpxiltools import GpxilFile
from gpxiltools.book import BookLayout, estimate_pages, make_book

layout = BookLayout(page="A4", dpi=300)
print(layout.grid(), f"{layout.bases_per_page():,} bases a page")
print(estimate_pages(3_088_286_401, 25, layout), "pages for GRCh38’s 25 chromosomes")
with GpxilFile("/data/grch38/chrM.gpxil.tif") as g:
    print(make_book(g, "/home/user/results/chrM.pdf", mode="reference", layout=layout))
