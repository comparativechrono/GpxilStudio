GpxilStudio

A gpxil file holds a genome as pictures: one pixel for every base of DNA, with a page for each chromosome and each kind of information – the reference’s bases, a person’s genotype, and how sure the calls are. GpxilStudio is a workbench for these files that runs entirely in your browser. You can look at a gpxil file, check it, make one from a person’s variants, draw any part of it, print it, get FASTA and VCF back out, make pictures of a person’s own version of a gene and its protein, compare genomes, and look for patterns in them. You can do all of this by pointing and clicking in the Tools tab, by typing commands in the Terminal tab, or by writing Python in the Notebook tab.

The formats, and the tools between them

A gpxil file is in the middle. A reference genome (FASTA) and a person’s variants (VCF) go in. Pictures, books to print, pictures of genes and proteins (pxil files), and FASTA and VCF again, come out. Each arrow is a tool: click one to open it, or click a box to see what you can do with that kind of file.

What there is to try

  • HG002’s chromosome 17 (/data/examples/HG002_chr17.gpxil.tif): the genome of a real person, from the Genome in a Bottle project’s benchmark, with their genotype at all 83 million bases. Its TP53 gene is a good place to start.
  • HG002’s TP53, as a window (/data/examples/HG002_TP53.gpxil.tif): TP53 and 100,000 bases either side, cut out of chromosome 17 into a file of 76 kB that keeps the chromosome’s positions.
  • The GRCh38 reference (/data/grch38): a gpxil file for every human chromosome, read from the Gpxil browser’s web site a piece at a time, so nothing has to be downloaded first.
  • Chromosome 17’s repeats and genes (/data/examples/rmsk_chr17.txt.gz, /data/examples/chr17_genes.bed): RepeatMasker’s 170,331 repeats and Ensembl’s 1,187 protein-coding genes, to stack, count substitutions in, and add to a genome as planes of their own (Pure GA-sequences).
  • The worked example of the gpxil specification: ten bases, four variants, small enough to read pixel by pixel (The codes).
Your files stay on this computer

Python and the tools run inside this web page. Your files are kept in this browser, on this computer, and are never sent anywhere. The only things the studio reads from the web are Python itself, when it first starts, and the GRCh38 reference and the gene files, which come from the Gpxil browser’s site. Privacy has the details, and Your files explains how to keep copies.
